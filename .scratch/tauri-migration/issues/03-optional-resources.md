## Answer

手工文件/提示词与可选目录、JSON 清单共用工作区。连接和资源元数据以同一 revision 保存；导入内容直接来自显式选择的来源，不持久化缓存，切换/清空同时清理该来源的收藏、最近访问和分类覆盖。Markdown 读取有深度、条目数、数量和总字节边界；JSON 清单文件入口经过 canonical 路径边界检查。文件入口仅在资源管理器中显示，不执行文件。

公共 Backend::call/save-reopen 回归覆盖未配置、接入/清空/切换、手工归属、内容更新、收藏/最近、暂停、旧版本拒绝覆盖、容量拒写、清单逃逸及重复身份、目录遍历上限与 Windows 换行。资源编辑器与连接编辑器保持挂载，失败保留草稿并显示冲突，搜索不依赖索引。父代理继续 Windows 原生 UI 演示和最终整体验收，因此本票暂保持 claimed。

本票验证：Rust resources 公共集成测试 6/6 通过；resources.mjs 与 app.mjs 的 Node 语法检查通过。未执行全量测试或原生 UI，留给父代理串行构建与实际演示。

主代理原生验收：真实 WebView 表单登记提示词，刷新保留输入及焦点，搜索、收藏、复制及最近访问通过；目录连接后清空，导入项消失且手工项保留。Windows 原生 JSON 选择框返回正确中文空格路径，清单导入成功，open_resource 成功发出 Explorer 定位请求。测试使用独立配置和 WebView 目录；文件夹中具体选中状态留最终发行验收。
